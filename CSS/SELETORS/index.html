Minha primeira aula de CSS

CSS é a sigla para Cascading Style Sheets, ou seja, Folhas de Estilo em Cascata. Ele é uma linguagem de estilo utilizada para descrever a apresentação de um documento escrito em HTML ou XML. O CSS é responsável por controlar a aparência visual de um site, permitindo que os desenvolvedores definam estilos para elementos como cores, fontes, espaçamento, layout e muito mais.
